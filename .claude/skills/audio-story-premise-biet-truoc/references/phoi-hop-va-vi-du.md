# Coordination And Examples For Foreknowledge Premises

This supplements `audio-story-premise-biet-truoc/SKILL.md`. Load it only when combining multiple skills, repairing a stiff premise expression, or checking research basis.

## 1. Combine With Genres And Other Premises

### Drama

Knowledge helps discovery or preparation; payoff remains the choice after betrayal. Do not turn other people into chess pieces because "I know what they will do."

### Mystery

Knowing the result shifts the mystery toward cause, proof, or new timeline. Do not let a system hand out the culprit's name. Fair play still applies to any promised solution; the book or old memory is only a scoped source.

### Horror

Foreknowledge can increase dread because the character recognizes signs but still cannot control execution. Loops need deltas; threats need rules; emotional reaction does not fully reset just because time resets.

### Romance

Second chances force the character to face the present person. Knowledge does not replace consent, prove "destiny," or justify manipulating the other person because of an old outcome.

### Comedy

Mismatch between prediction and the world's response can create a comic engine. Do not make the character fail every time just for jokes; give them real competence and let the premise deviation create new consequences.

### Truyen-Rac

Other characters may repeat biases, but the foreknowing character's new actions must make the world react. Do not use "everyone is foolish as before" to create free victory. Release type is decided by the main genre and the compressed debt.

## 2. Repair Examples

### Only Declaring Foreknowledge

**Stiff:**

> *Tôi biết mọi thứ vì đã đọc cuốn sách. Cảnh này được viết sẵn từng chữ.*

**Concrete:**

> *Tôi nhớ ba việc ở lễ cưới: tờ xét nghiệm là giả, người đổi mẫu đeo nhẫn ngọc xanh, và camera hành lang sẽ mất đúng tám phút. Tôi không biết tên người đó; cuốn sách chỉ kể cảnh từ trong phòng cô dâu.*

Known and unknown scope creates an action path.

### Arbitrary Butterfly Effect

**Weak:** character changes one sentence, and every later event randomly changes.

**Better:** the sentence keeps the younger sister in the lobby, so she sees the sample-switcher; the culprit notices and changes plan. Changes follow causality.

### Omnipotent System

**Weak:** system assigns tasks, identifies culprit, grants exactly needed skill.

**Better:** system measures one narrow variable such as "deviation from original plot"; the character must interpret and may exploit it, but does not receive answers.

### Reincarnation Only For Revenge

**Thin:** character remembers everything, avoids every trap, villains lose one by one.

**Deeper:** knowledge avoids the first trap but forces the character to realize old-life revenge used an innocent person as evidence; the second life becomes a choice between clean revenge and saving that person.

### Pure Transmigration Knows Too Much

**Stiff:** modern character precisely remembers technology, history, and medicine.

**Natural:** they bring knowledge that fits their profession; everything else is hypothesis tested against local resources and rules.

## 3. Quick Trap Table

| Trap | Repair |
|---|---|
| All variants become "knows everything" | Choose module and lock knowledge scope |
| Pure transmigration forced into original-plot mechanic | Use transferred knowledge/skill, not plot foreknowledge |
| System = omniscient narrator | Specify observation, goal, reliability |
| Book transmigration knows off-page scenes | Follow read POV/version |
| "Script corrects itself" without setup | Use only as defined and tested law |
| Every prediction must fail for tension | Shift question to execution, proof, ethics, or cost |
| Butterfly effect = randomness | Follow causal path from changed action |
| Advantage price always lifespan/points | Choose information, social, ethical, execution, or identity limits |
| Opponent also reincarnates as difficulty button | Add only with thematic/plot function and foreshadowing |
| Twist "old life fake/system lied" by default | Keep rules trustworthy; twists need signs and consequences |
| Foreknowledge removes others' agency | Let others react to new information and make choices |
| Opening with info-dump | Current situation + premise proof + knowledge + action |
| Mandatory explanation of who caused the reset | Explain only if promised or needed for payoff |
| UI tags in pure story | Write in prose; production cue only if requested |

## 4. Research Basis

- [PubMed: Counterfactual thought](https://pubmed.ncbi.nlm.nih.gov/26393873/) — counterfactuals help explain the past, prepare the future, reason causally, and affect regret/blame.
- [PubMed: Regret, disappointment and counterfactual outcomes](https://pubmed.ncbi.nlm.nih.gov/9719660/) — regret links more to changing one's action; disappointment more to changing circumstances. Useful for "do-over" arcs.
- [Frontiers in Psychology: Uncertainty and suspense](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2018.01392/full) — suspense can exist when outcome is known; no need to break every prediction.
- [PubMed: Causal integration in narrative comprehension](https://pubmed.ncbi.nlm.nih.gov/34531284/) — causal relations support event integration.
- [ACL: A framework for narrative surprise](https://aclanthology.org/2025.wnu-1.7/) — twists need expectation violation plus retrospective coherence.
